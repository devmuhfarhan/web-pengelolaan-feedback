# Puspadi Bali Portal - Panduan Menjalankan Aplikasi

Aplikasi ini menggunakan teknologi berikut:
- **Backend**: Python (Django REST Framework) + MySQL (sebagai database utama)
- **Frontend**: Javascript (React / Vite)

Untuk memudahkan Client maupun Penguji menjalankan aplikasi ini, kami menyediakan **dua (2) opsi cara menjalankan**:

---

## 🚀 OPSYEN A: Menggunakan Docker & Docker Compose (SANGAT DIREKOMENDASIKAN)
*Gunakan opsi ini jika komputer Anda tidak memiliki instalasi Python, Node.js, atau MySQL. Opsi ini hanya membutuhkan Docker Desktop saja.*

### Prasyarat:
- Sudah menginstal **Docker** dan **Docker Compose** (atau **Docker Desktop**).

### Langkah-langkah:
1. Buka terminal/command prompt di direktori root proyek ini (`web-pengelolaan-feedback`).
2. Jalankan perintah berikut untuk mengunduh dan membangun semua service secara otomatis:
   ```bash
   docker-compose up --build
   ```
3. Docker secara otomatis akan:
   - Membuat container database MySQL & mendirikan database `db_pengelolaan_feedback`.
   - Menjalankan migrasi tabel backend Django.
   - Mengisi data uji coba secara otomatis (**Seed Data**).
   - Membangun server frontend React Vite.
4. Setelah terminal menampilkan pesan server backend dan frontend berjalan, Anda bisa langsung mengakses aplikasi di browser:
   - **Frontend**: `http://localhost:5173/`
   - **Backend API**: `http://localhost:8000/`

---

## 🛠️ OPSYEN B: Menggunakan Instalasi Manual Lokal
*Gunakan opsi ini jika Anda ingin menjalankan aplikasi secara manual menggunakan tools (Python, Node.js, MySQL) yang terpasang langsung di sistem lokal.*

### Prasyarat:
- **Python**: Versi 3.10 ke atas terpasang.
- **Node.js**: Versi 18 ke atas terpasang.
- **MySQL**: Layanan MySQL Server terpasang dan berjalan (port default `3306`).

### Langkah 1: Setup Database MySQL
1. Pastikan server MySQL lokal Anda berjalan.
2. Buat database baru bernama `db_pengelolaan_feedback`. Jika password root MySQL Anda bukan `root`, Anda bisa menyesuaikannya di file `backend/core/settings.py` pada bagian `DATABASES`.
3. Alternatif otomatis (menjalankan script pembuat database otomatis):
   ```bash
   cd backend
   python db_setup.py
   ```

### Langkah 2: Setup Backend (Django REST Framework)
1. Buka terminal dan masuk ke folder `backend`:
   ```bash
   cd backend
   ```
2. Buat dan aktifkan **virtual environment** (venv):
   - **Windows (Command Prompt / Powershell)**:
     ```bash
     python -m venv venv
     .\venv\Scripts\activate
     ```
   - **macOS / Linux**:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
3. Pasang semua pustaka dependensi:
   ```bash
   pip install -r requirements.txt
   ```
4. Jalankan perintah migrasi tabel database:
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   ```
5. Isi database dengan data uji coba awal (akun default, program, dll.):
   ```bash
   python manage.py seed_data
   ```
6. Jalankan server backend:
   ```bash
   python manage.py runserver
   ```
   *Server backend sekarang berjalan di `http://127.0.0.1:8000/`.*

### Langkah 3: Setup Frontend (React / Vite)
1. Buka terminal baru dan masuk ke folder `frontend`:
   ```bash
   cd frontend
   ```
2. Pasang semua dependensi NPM:
   ```bash
   npm install
   ```
3. Jalankan server frontend dalam mode development:
   ```bash
   npm run dev
   ```
   *Aplikasi frontend sekarang berjalan di `http://localhost:5173/`.*

## 📌 Fitur Baru yang Ditambahkan & Catatan Pengujian (UAT Highlights)

Untuk mempermudah verifikasi hasil pengerjaan (Sesuai Revisi Klien Terakhir), berikut adalah ringkasan fitur baru yang telah diimplementasikan:

1. **Internasionalisasi / Bahasa Inggris**:
   - Seluruh teks UI dari Menu Dashboard, Feedback, Penerima Manfaat, hingga Program sekarang menggunakan bahasa Inggris.
   - Istilah "Program Kerja" telah disesuaikan dan diubah secara konsisten menjadi "Program".
   - Untuk Manager, label "Start Date" telah diubah menjadi "Implementation Date" pada modul Program.

2. **Manajemen Data Penerima Manfaat (Beneficiaries)**:
   - **Perubahan Struktur Data**: Kolom form `Email` dan `Password` telah dihapus saat proses tambah Penerima Manfaat. Username untuk beneficiary sekarang digenerasi secara otomatis dan mandiri (cth: `penerima_xxxx`).
   - **Riwayat Penggantian (Replacement History)**: Data pergantian tanggal sekarang tidak menimpa / override data lama. Jika ada pembaruan tanggal/program penggantian, staf bisa menekan "Add Replacement" untuk mendata histori secara vertikal.
   - **Log Modifikasi (Audit Trail)**: Panel rincian informasi menambahkan data tentang "Last Modified By" yang menyimpan riwayat User ID siapa yang paling akhir memodifikasi profil tersebut.
   - **Restriksi Staff Lapangan**: Akun dengan Role "Staff Lapangan" secara default tidak dapat mengakses fungsi _Edit_ maupun _Delete_ pada manajemen Penerima Manfaat. (Semuanya disembunyikan / dikunci).

3. **Sistem Feedback Modern & Log Data JSON**:
   - Skema kuesioner pada form "Submit Feedback" telah diubah total menjadi 10 Pertanyaan Spesifik berbahasa Inggris sesuai pesanan.
   - Rating yang tadinya rentang 1-5 diubah menggunakan skala Likert point 1 hingga 4.
   - Hasil kalkulasi dan respons pertanyaan disimpan menggunakan format JSON di database, memungkinkan tracking skor dari pertanyaan-pertanyaan spesifik dan export yang rapi.

4. **Kumpulan Data Bersih (Puspadi Clean Programs)**:
   - Dummy data untuk program telah dihapus.
   - Aplikasi di-seed menggunakan set data program asli Puspadi (cth: _Rehabilitasi, Pendidikan, Pelatihan & Pemberdayaan, Advokasi_) ketika script `seed_data` dieksekusi.
